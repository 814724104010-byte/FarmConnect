# 🌾 FarmConnect – Farmer-Consumer Interface

**Goal:** Support **SDG 2: Zero Hunger** by connecting farmers and consumers directly via a simple Firebase-based platform.

## 🚀 Features
- Farmers can add crops with images and prices.
- Consumers can browse products and place basic orders.
- No authentication required (MVP version).
- Firebase Realtime Database + Storage + Cloud Functions.

## 🧰 Tech Stack
- Firebase (Realtime Database, Storage, Functions)
- HTML, CSS, JavaScript
- Hosted on Firebase Hosting
